Different native pattern lengths provably distinguish all five part positions; observed 18/19 updates per part with same wire revision and changing index, exact DOM cursor agreement, then native 127 sentinel and DOM clear. Reproduce: apply only wasm-midi-transport-position.patch to exact tree in private checkout. Use standard bundled Playwright, set DNBOX_RELEASE_PACKAGES to the immutable stable package directory, DNBOX_FWUI_RUNTIME to pinned public firmware reference, DNBOX_EMULATOR_RUNTIME to runtime-owner-8f97, and run npm run build. Then set DNBOX_EMULATOR_RUNTIME to runtime-adf3eee, DNBOX_AUDIT_SITE to .output/product-site absolute path and run python3 tests/product-remote/wasm-midi-transport-position-browser.py. This is scoped local real-WASM evidence on the saved developmental runtime, not a freshly built composed dev firmware, physical device, native fit, whole browser e2e or release gate.
