# Strict native played-note typed Remote continuation

Apply the prior typed firmware patch on the exact DNR3 donor and add
fold.patch to the compact Synth One delay read. The disabled or short
warm delay uses 16 samples, but the legacy reader can make hundreds of
repeated +16 iterations each sample to wrap a normal delay time. The
bounded quotient removes whole additions without changing the final
fractional position, and does not skip warm history updates. Per-tap
unit evidence and an independent 307,200-frame full host parity witness
are described in HANDOFF.md.

The actual new owner-generation-guarded package finishes strict emulated
USB cutoff 115 to 120 while a note is active on both models, on this S1
original-ID route. It received independent VOICE, echoed QUEUED and only
then returned the new value on actual GET. It uses a fresh disposable
startup for lease and old-value calibration. No real device or flash was
used. This is not the 922-event heavy gate.

- Elite: 4,504 B XIP free, 512 B POOL margin; 12,219 µs, 30 late/xruns.
- Pro: 4,516 B XIP free, 512 B POOL margin; 12,262 µs, 31 late/xruns.

So the new protocol is usable in this short native emulation, but audio
performance still blocks release. This neither qualifies SuperJ6 typed
native links nor the full new control UI, nor the browser/physical cable.

Reproduce with native-play.sh exactly as previous native-script.sh:
set DNR3_WEB to its patched web codec, FM1_EMU to the authenticated native
harness, supply a fresh output folder and the exact package from the
guarded fold build. read-telemetry.py takes the matching model ELF and
the edit subfolder. Do not attach or commit emulator flash, RAM or audio.
