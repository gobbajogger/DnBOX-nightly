Import replaces the live project and the sample slots shown above. Save on keyboard stores it immediately; autosave also applies.

Details: import checks

The firmware validates the project before sample changes, verifies the written samples, then adopts the project.

The recovery backup from the interrupted import is still available, even if you close its preview or choose another file.

03 Keep a copy

Details: project files

Portable files retain original sample bytes, playback rates and slot order. Without samples, a file imports only when every sample slot already matches.

04 On the keyboard

Load replaces the live project. Reset clears the whole live project: song arrangement, patterns, sounds and project settings. Samples stay. Reset turns autosave on and may overwrite the saved project. Export first to keep your work.

Details: reset & recovery

Reset also clears motion and stops playback and recording; device role settings stay in place. Arrangement-only clear is unavailable in this browser. To clear only the arrangement, use SONG → CLEAR SONG on the keyboard, keeping patterns, sounds, settings and samples.

Keep USB connected during transfers. After a sample-transfer failure, the page attempts to restore the previous samples and reports the result. Keep the recovery file for reconnecting.
