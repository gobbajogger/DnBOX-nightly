Install nightly

Your presets. Their original format.

Open, preview and save a separate copy in the original format.

1 · Open an original file

The file is checked before you can keep a copy. Download names start with original- or kept-. Kept copies use the format’s extension: .synth1 for SynthOne singles, .json for banks.

2 · Inspect and optionally rename

Choose a file to preview.

3 · Save a separate copy

Your sequences, arpeggios, effects, tuning and all other preset data stay unchanged. You can edit only an existing preset name.
