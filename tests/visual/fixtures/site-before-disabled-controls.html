Read, check and back up user-made engine presets without changing the keyboard. This page never writes to the instrument or uploads files to a server.

01 / Open preset files

Drop files here or use the file picker. Each record is checked for CRC, length, engine, format and schema before being kept in this browser session.

Hardware model is not encoded in DNPR v1. An explicit Elite/Pro filename suffix can be checked for conflict, but real model compatibility requires a future device identity handshake. File-only inspection works without a device.

Choose a file to inspect. Nothing is sent or saved automatically.

02 / Review

A validated file preview will appear here before it enters the session.
