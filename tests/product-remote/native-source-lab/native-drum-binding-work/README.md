# Settled source binding for the63-control drum census

No app registration, firmware catalog or device permission. Exact b341 typed identities and complete required local draft values are required; dependent BD values are captured once per key. Every selected committed raw is integer and bounded. Canonical names remain lookup identities; presentation must use native readable captions, including Depth rather than P.Dpth. This code does not render labels.

Four unit tests exercise all7,434 raw states, rejection, nonmutation and current dependency capture. Full source-pipeline comparison additionally matches every native RGB565 byte for63controls/7,434 frames at the original fixed64×48 crop, idle state, source scales/origin/colors. The retained buffers are read locally only, never emitted or uploaded. Input sweep/index hashes, each control metadata hash and each raw-buffer SHA are checked before comparison.

Run node --test drum.test.mjs. For the separate local raster comparison, set DNBOX_NATIVE_SWEEP_URL to a file URL for the authorized retained sweep fixture, then run node full-raster-parity.mjs. No automatic download or alternate publication of denied raw archives is performed.

Not proven: dynamic/eased values, live highlights/envelopes, cache/clock ownership, browser pixels, whole native layout, voice switching, current remote app binding or a lane gate. Numeric SI source tables retain actual unit IDs, float bits and state provenance; unknown units are not newly invented units. Source-family geometry review is separate from this typed orchestration test.
