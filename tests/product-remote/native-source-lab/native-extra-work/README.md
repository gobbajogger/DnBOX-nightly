# Remaining current-native idle drum families

Unbound source port of native LPF Tone, Shells, Snappy, Accent and discrete Sound fallback glyphs. These cover the remaining11 controls in the63-control current drum glyph census. Exact code and math are from b341, not invented normalized audio laws. Maximum1 Sound values are discrete engine values; fractional test values only probe native presentation interpolation.

45,955 native math comparisons and8,164 geometry cases/236,696 coordinates match staged native C float32. Scope is idle only (live=false, envelope0); no live-burst, browser, raster, layout or app binding qualification. Source source/header bytes are captured, pinned and staged for compilation, with before/after checks and bounded subprocesses.

Run node parity.mjs; python build-geometry.py; node geometry-parity.mjs. Executables are local test products, not publication artifacts.
