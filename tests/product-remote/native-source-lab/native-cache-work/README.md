# Source-native16-slot presentation cache model

Unbound port of b341 ui_glyph_renderer.h cache/clock behavior plus the independently checked native arithmetic step.661 command events compare all10,576 slot snapshots against the actual extracted C functions: target changes, repeated identities,16-slot eviction, unsigned frame ordering across wrap, unsigned time wrap/rollback, initialization/reset and slow-frame snap. Bank tags exercise only the existing cache family discriminator; they do not describe or admit an audio engine.

The JavaScript accepts bounded byte identities, integer target0..255 and unsigned clocks/frames. Invalid inputs leave state unchanged; caller committed controls and identities are not mutated. This is presentation state only.

No browser RAF/lifecycle ownership, real hardware clock, native display cadence, live audio state or end-to-end animation qualification. The constructor's cache is an isolated model, not a global browser engine. A future app wrapper must preserve stale-callback cancellation and source context.

Run python build-reference.py; node parity.mjs; node --test cache.test.mjs. C/header source is captured/hash-checked and staged before compilation; source bytes and compiled binary hashes are verified around execution. No binaries are published.
